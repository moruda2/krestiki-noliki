# Крестики · Задачник

Тактический этюдник по крестикам-ноликам в духе шахматных задач. На каждой
позиции у крестиков есть **ровно один** выигрышный ход — любой другой
проигрывает партию следующим же ходом соперника.

[Играть](https://moruda2.github.io/krestiki-noliki/) · Tier-ов три: **3×3 Classic**,
**4×4 Wide**, **5×5 Master** — последние два играются до четырёх в ряд.

## Стек

- Чистый HTML / CSS / JS, без сборки и фреймворков
- Пазлы лежат в `puzzles.json`, генерируются офлайн скриптом на Node
- Деплой — GitHub Pages из ветки `main`

## Запуск локально

```bash
python3 -m http.server 8765
# открыть http://localhost:8765/
```

Прогресс хранится в `localStorage` под ключами `krestiki:progress` и
`krestiki:pos`.

## Регенерация пазлов

`tools/generate.mjs` — отдельный Node-скрипт без зависимостей.

```bash
node tools/generate.mjs > puzzles.json
```

Алгоритм:

1. Для **3×3** — полный перебор всех достижимых позиций (X ходит).
2. Для **4×4** и **5×5** — случайная выборка позиций с разным числом фигур.
3. Для каждой позиции на каждый ход X запускается мини-макс с ограничением
   по глубине: 6 / 4 / 3 полу-ходов соответственно.
4. Позиция оставляется только если **ровно один** ход X ведёт к победе с
   оптимальной игрой, а все остальные ходы — к поражению.
5. Симметрии (повороты + отражения, D₄) сворачиваются в каноническую форму
   для дедупликации.
6. Категория хода (`immediate` / `block-and-win` / `fork` / `trap`) и
   сложность считаются эвристикой.

Параметры (количество пазлов на тир, глубина поиска, размер выборки) лежат
в массиве `VARIANTS` в начале файла.

## Структура

```
index.html           — разметка
styles.css           — токены и анимации
app.js               — состояние, рендер, игровая логика
puzzles.json         — банк пазлов
tools/generate.mjs   — генератор
.github/workflows/   — деплой на Pages
```

## Деплой

После push в `main` GitHub Actions запускает workflow `pages.yml`, который
публикует корень репозитория на GitHub Pages. Адрес —
`https://moruda2.github.io/krestiki-noliki/`.

Если репозиторий приватный, для GitHub Pages нужен платный план (Pro/Team).
Для бесплатного аккаунта — сделать репу публичной либо деплоить через
Vercel / Netlify.
